A bold, tabloid-style front page rendered as a single news image for the
`news-image-20261121` make.fun bounty. A small Node 22 stdlib-only script
copies the finished artwork into the configured output directory.

## Run it

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose the destination (defaults to `/output`).
